# SkillArk v0.7 测试与逆向验证计划

## 1. 逆向思维：该版本最可能如何失败

| 翻车方式 | 影响 | 设计防线 |
|---|---|---|
| Windows 路径被错误映射到 WSL | 写错位置或数据损坏 | 不做字符串替换；通过目标环境 helper canonicalize。 |
| WSL 未运行或发行版删除 | 任务挂起 | 状态机、启动超时、明确 unavailable，不自动创建发行版。 |
| macOS 签名/权限问题 | 无法安装或更新 | 发布前独立签名/公证 Spike；失败则保持 Beta 手动安装。 |
| 跨环境事务假象 | 一个失败拖垮全部 | 子计划独立提交；UI 显示部分成功。 |

## 2. 测试层级

### Unit

- 规范化、状态机、策略、Hash 和错误映射。
- 所有纯函数使用表驱动测试与性质测试。

### Contract

- 外部来源、模型、环境或扩展使用录制响应和契约样本。
- API 字段缺失、类型变化、分页漂移必须覆盖。

### Integration

- SQLite 迁移、缓存、文件系统、任务取消和恢复。
- 成功与失败的数据库/文件系统顺序组合。

### End-to-End

- 从 UI 输入到可验证结果、回滚和诊断。
- 离线、权限不足、部分成功、旧数据升级和多语言路径。

## 3. 故障注入矩阵

| 阶段 | 故障 | 预期 |
|---|---|---|
| 获取/解析 | 超时、限流、内容改变 | 保留旧状态，标 stale/failed，可重试 |
| 临时存储 | 磁盘满、权限不足 | 不提交业务记录，清理或登记临时项 |
| 数据库 | commit 失败 | 文件状态回滚或进入 recovery_required |
| 文件替换 | 重命名失败、目标被占用 | 原目标保持可用，不标成功 |
| 验证 | Hash/证据不一致 | 不提交成功，保留诊断 |
| 回滚 | 备份损坏 | 进入恢复中心，禁止静默继续 |
| 进程 | 强杀/系统重启 | 下次启动识别 Operation 并修复 |

## 4. 安全与隐私测试

- 路径穿越、Zip Slip、符号链接逃逸。
- Token/API Key/环境变量不进入日志、错误、遥测和诊断。
- 外部文本不能改变系统策略或获得未声明能力。
- 资源耗尽：超大文件、深层目录、压缩炸弹、无限分页。

## 5. 发布门禁

- 关键假设实验通过。
- P0/P1 自动化测试通过。
- 100 次关键流程故障注入无数据损坏。
- 真实升级副本完成备份、迁移、失败恢复。
- 文档与已知限制和实际支持矩阵一致。
