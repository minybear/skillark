# SkillArk v1.0 架构决策记录

> ADR 只有在证据变化或假设被证伪时重新打开，不因实现方便而绕过。

## ADR-1001

**决策：** 只有真实使用且通过兼容测试的接口进入 v1 稳定面。

**原因：** 满足本版本的不可约简用户结果，同时保留失败降级和后续替换能力。

**反例/代价：** 该决策不是普遍最佳；若对应 H 假设失败，应按证伪结果重新打开 ADR。

**验证：** 通过本版本 POC、故障注入和发布门禁。

## 开放决策

- 所有 U 未知项在版本 POC 结束前必须关闭、降级为明确限制或推迟版本。
