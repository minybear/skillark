# SkillArk v0.1 项目启动 · 需求概览

状态：进行中（M0 已完成，M1 进行中）  
创建日期：20260725  
当前阶段：M1（四个内置 Agent 探测已落地，补 Custom 与验证矩阵）

## 一句话目标

以现有设计包为基线，建立可持续归档的项目文档体系，冻结 v0.1 范围和契约，并依次完成 Agent 探测、Skill 导入与安全分发 POC，最终交付 Windows 本地优先 MVP。

## 背景

SkillArk 解决同一个 Skill 在多个 AI Agent 和多个项目中重复安装、版本失控、路径不一致及 Windows 手工复制易出错的问题。核心价值是：

> 导入一次，选择目标，一次分发；随时查看每个目标是否同步。

本计划以 `docs/skillark/design/v0.1/` 的 9 份设计文档、3 个 JSON Schema、SQLite 初始模型和 Rust 接口示例为输入。

## v0.1 范围

- Windows 本地桌面应用。
- 导入本地 Skill 目录或 ZIP，并生成受管、不可变版本快照。
- 扫描和配置 Claude Code、Cursor、Codex、WorkBuddy、Custom Agent。
- 管理全局和项目 Workspace。
- 先生成结构化安装计划，再以 Copy 或 Junction 分发。
- 支持冲突识别、验证、重新分发和安全卸载。
- 所有写操作留存可审计 Operation。

## v0.1 不做

- 公共市场、多 Hub 聚合、GitHub 来源。
- 云端账号与跨设备同步。
- AI 自动执行任意安装命令。
- Bash/PowerShell 自动转换和兼容评分。
- macOS、Linux、WSL 正式支持。
- 企业权限、付费、评论、收藏和排行。

## 里程碑

| 里程碑 | 目标 | 退出条件 |
|---|---|---|
| M0 设计冻结 | 统一范围、DTO、状态机、数据库方案 | 高优先级设计问题关闭 |
| M1 Agent 探测 POC | 多信号发现并允许人工修正 | 至少 3 个 Agent 得到可确认 Skill 目录，扫描 < 3 秒 |
| M2 导入与分发 POC | 受管版本、Copy/Junction、验证和卸载 | 一个 Skill 分发到至少 3 个测试目标；失败不破坏原目标 |
| M3 完整 MVP UI | 完成首次启动、Library、Agent、Workspace 和分发向导 | 核心 E2E 全部通过 |
| M4 v0.1 发布 | 安装、升级、迁移、真机回归 | 发布门禁全部通过 |

## 总体验收

- 在至少两台 Windows 设备验证。
- 覆盖中文、空格、括号、OneDrive 和权限不足路径。
- 验证至少 20 个结构不同的 Skill。
- Copy/Junction 安装、验证、冲突处理、卸载通过。
- 任意失败不得静默覆盖非受管目录或留下不可识别半成品。
