# SkillArk v0.1 项目启动 · 测试用例

## 核心用例

| ID | 场景 | 预期 |
|---|---|---|
| CT-001 | Rust AgentCandidate 序列化后按 Schema 校验 | 使用冻结后的 `agentType` 字段且校验通过 |
| CT-002 | DeploymentPlan 缺少目标或 workspaceId | Schema 拒绝并返回可定位错误 |
| AG-001 | PATH、配置目录和 Skill 目录均存在 | 得分达到 detected，展示全部信号 |
| AG-002 | CLI 存在但 Skill 目录不存在 | 标记 probable 或需创建，不抛异常 |
| AG-003 | 用户手动设置路径后重新扫描 | 保留用户设置，自动结果只作提示 |
| AG-004 | 四类内置 Agent 均未安装 | 扫描正常结束，应用可继续使用 Custom |
| IM-001 | 导入只有 SKILL.md 的合法目录 | 生成 Skill、SkillVersion、manifest 和稳定 Hash |
| IM-002 | 同一内容重复导入 | 复用相同内容版本，不重复存储 |
| IM-003 | ZIP 包含 `../` 逃逸条目 | 整包拒绝，目标外无任何文件写入 |
| IM-004 | Skill 内链接逃出根目录 | 拒绝或报告高风险，不跟随读取 |
| DP-001 | Copy 到不存在的目标 | 计划为 none，安装后 Hash 相等且状态 synced |
| DP-002 | 目标为非受管合法 Skill | 分类 unmanaged_skill，未确认前不写入 |
| DP-003 | 受管 Copy 目标被用户修改 | 状态 modified，不静默覆盖或删除 |
| DP-004 | Copy 20% 时注入失败 | 原目标仍可用，Operation failed，可清理临时目录 |
| DP-005 | Junction 指向正确 Library 目录 | 安装、验证和卸载均只操作链接本身 |
| DP-006 | Junction 被改指其他目录 | 状态 modified，卸载前要求用户处理 |
| DP-007 | 多目标中一个权限不足 | 其他目标继续执行，结果逐目标展示 |
| DP-008 | 目标为磁盘根、用户主目录或系统目录 | 计划阶段阻断，不提供强制执行 |
| DB-001 | 空数据库执行初始 migration | 所有表与索引创建成功，可重复启动 |
| DB-002 | 文件写入成功但数据库提交失败 | 恢复或标记可恢复操作，不出现虚假 synced |
| UI-001 | Library 没有 Skill | 显示 empty 状态和“添加 Skill”入口 |
| UI-002 | 批量分发部分失败 | 显示每个目标结果，可仅重试失败项 |
| PF-001 | 500 个本地 Skill 首次列表加载 | 小于 2 秒 |
| PF-002 | 100 个 Agent/Workspace 目标验证 | 小于 5 秒，可取消并显示进度 |

## 边界数据

- 中文、空格、括号和长路径。
- 1000 个小文件与单文件大于 20 MB。
- 空描述、重复名称、未知格式和损坏 ZIP。
- 只读父目录、目标被占用、OneDrive 同步延迟。
- 应用崩溃后残留的 running Operation、临时目录和备份目录。
