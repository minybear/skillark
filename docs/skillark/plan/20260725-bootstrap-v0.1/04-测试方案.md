# SkillArk v0.1 项目启动 · 测试方案

## 测试目标

验证 SkillArk 在 Windows 上能够确定性、安全、可恢复地导入和分发 Skill，并保证领域规则、序列化契约、数据库状态与真实文件系统一致。

## 测试层级

| 层级 | 覆盖 |
|---|---|
| Contract | Rust DTO 与 JSON Schema 的正反例；字段命名、必填项、枚举和 nullable 规则 |
| Unit | SKILL.md 解析、路径规范化、Hash、冲突分类、状态计算、Agent 评分 |
| Integration | SQLite repositories、目录/ZIP 导入、Copy/Junction Driver、Operation 补偿流程 |
| End-to-End | 首次启动、Agent 扫描与修正、导入、Workspace、多目标分发、验证和卸载 |
| Fault injection | 复制、校验、备份、重命名、数据库提交和清理阶段失败 |
| Security | Zip Slip、逃逸链接/重解析点、危险目标路径、权限不足、敏感日志 |

## Windows 环境矩阵

- Windows 11 普通用户。
- Windows 11 开发者模式开启。
- NTFS 同盘和跨盘。
- 中文用户名和中文目录。
- 路径含空格、括号与长路径。
- OneDrive 同步目录。
- 只读、权限不足和目标被占用。

## 测试夹具

建立 `test-fixtures/skills/`，至少包括：

- `minimal-valid`
- `full-valid`
- `invalid-no-frontmatter`
- `invalid-no-name`
- `duplicate-name`
- `nested-assets`
- `unicode-paths`
- `many-small-files`
- `large-file`
- `internal-symlink`
- `escaping-symlink`
- `malicious-zip-slip`

## 故障注入点

1. 复制 20% 时失败。
2. 复制完成、Hash 校验前失败。
3. 备份旧目录后失败。
4. 临时目录重命名前失败。
5. 文件完成但数据库提交失败。
6. 数据库完成但清理备份失败。

每个故障必须断言：原目标是否仍可用、临时/备份目录如何恢复、Operation 最终状态和下次启动清理行为。

## 发布门禁

- 单元与契约测试全部通过。
- 核心集成和 E2E 测试全部通过。
- 无高等级路径穿越或静默数据丢失问题。
- 安装包全新安装与覆盖升级通过。
- migration 在真实旧数据副本上通过。
- PRD 中的性能和双机验收达标。
