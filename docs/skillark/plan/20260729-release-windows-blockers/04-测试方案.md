# 测试方案

## 自动化

- Deploy UI：Junction 部分失败时显示 Copy 重试；成功目标不重试；新计划模式为 Copy。
- 后端：保留既有 Copy/Junction、路径安全、迁移和数据集 E2E。
- 路径矩阵：中文、空格、括号、长路径运行时生成并完成 import → plan → copy → verify。

## 安装包

- 构建：NSIS setup 产出且 SHA-256 可记录。
- 全新安装：干净用户环境安装、启动、导入、Copy 部署。
- 覆盖升级：旧版本安装后制造真实数据，再安装新版本，验证数据库与数据保留。

## 环境矩阵

| 场景 | 当前机器替代方式 | 判定 |
|---|---|---|
| 跨盘 | 已有第二卷或临时 VHD | Copy 部署与 verify 成功 |
| 只读/权限不足 | ACL 禁止写入的测试目录 | 操作失败且不留半成品 |
| Junction + EDR | 当前 EDR | 失败可被识别并提供 Copy 重试 |
| OneDrive | 真实已同步目录 | 部署、同步扰动后 verify 结果正确 |
| 独立 Windows | 干净 VM 或第二台设备 | 全新安装、覆盖升级、Junction 回归 |
