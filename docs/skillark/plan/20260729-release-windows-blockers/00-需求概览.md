# 20260729 Windows 发布阻塞项收尾

## 目标

闭环 SkillArk v0.1 的 Windows 发布阻塞项：产出 NSIS 安装包、为 Junction 受安全软件拦截提供可恢复的 Copy 降级路径、清理已被自动化测试替代的手工 fixture，并补齐当前环境可执行的路径矩阵证据。

## 范围

- 仅从 Tauri 官方 `tauri-apps/binary-releases` 获取 NSIS 工具链。
- Junction 执行失败时保留原始失败，并允许用户显式切换 Copy 重试。
- 删除 `test-fixtures/skills/中文 Skill (E2E)`，更新证据账本引用。
- 执行自动化测试以及本机可模拟的跨盘/权限矩阵。
- 更新工作日志、发布审计及关联 issue。

## 边界

- 不绕过 EDR，不使用第三方下载代理。
- 不静默把 Junction 改成 Copy。
- OneDrive 真同步目录和独立 Windows 环境若当前机器不可用，保留为外部验证项，不伪造通过证据。
- 本轮不处理代码签名与自动更新。
