# M2 · v0.1 核心 · 开发计划

## 任务拆分（每步独立可测，逐步 `cargo test`）

| # | 任务 | 依赖 | 验收点 |
|---:|---|---|---|
| A0 | Cargo 依赖（zip / junction / dev tokio） | — | `cargo build` 通过 |
| A1 | domain：`DeploymentRecord`、`Operation`、`VerifyResult`、`DriftReason` | — | domain 单测通过 |
| A2 | ports：`DeploymentDriver` 补全、新增 `SkillSourceAdapter`/`FileHasher` | A1 | 编译通过 |
| A3 | adapters/filesystem：递归 copy + 原子 rename + 备份/回滚 | — | filesystem 单测（含逃逸链跳过） |
| A4 | adapters/sources：local_dir + zip（Zip Slip） | A2 | 解析 + zip slip 单测 |
| A5 | adapters/deployment：Copy Driver（preflight/install/verify/uninstall） | A2,A3 | 8 冲突分类 + 补偿事务 + 故障注入单测 |
| A6 | adapters/deployment：Junction Driver（Windows） | A2 | 安装/验证/卸载 `#[cfg(windows)]` 单测 |
| A7 | repositories：Deployment / Operation / Workspace；Skill 仓库扩展 | A1 | 仓库集成测试（`:memory:`） |
| A8 | application：AppState + vault/DB 接线 + import/plan/execute/verify/uninstall | A4–A7 | 服务层集成测试（端到端文件系统） |
| A9 | commands：DTO + `#[tauri::command]` 全量接通 | A8 | contracts 测试 + clippy 通过 |
| A10 | lib.rs：启动建池、管理 AppState | A9 | `tauri dev` 可起；命令可调 |
| B1 | 前端 api + shared 类型（skills/deploy/operations） | A10 | `npm run typecheck` 通过 |
| B2 | Library 页（列表 + 导入目录/ZIP） | B1 | 浏览器/桌面端可导入并刷新 |
| B3 | 分发向导（选 skill → scope → agent → 模式冲突 → 确认 → 结果） | B1 | 走通一次多目标分发 |
| B4 | 操作记录页 + 首页统计 | B1 | 列出最近 operation 与 synced/outdated 计数 |
| C1 | 数据库备份辅助 + `tauri build --debug --no-bundle` 验证 | A10 | debug 包可出；备份/恢复单测 |

## 阶段顺序

```text
A0..A2 (domain/ports) → A3..A7 (adapter/repo) → A8 (service 编排)
  → A9..A10 (command/state) → B1..B4 (UI) → C1 (发布可行项)
```

## 执行约束

- 每个 A# 完成后跑 `cargo test --manifest-path src-tauri/Cargo.toml --all-targets`，必须全绿才进下一步。
- 每个 B# 完成后跑 `npm run check`，必须全绿。
- 收尾：更新 bootstrap phase 文案、写当日 worklog（`write-worklog`）、更新 `03-开发计划.md` 进度表。
