# M2 · v0.1 核心功能（导入 + 分发 + 审计）

> 对应 `docs/skillark/plan/20260725-bootstrap-v0.1/03-开发计划.md` 中的 Task 7–11。
> 设计依据已冻结于 `docs/skillark/design/v0.1/`（PRD / ARCHITECTURE / DEPLOYMENT-POC / DATA-MODEL），本目录只补充"怎么落到当前代码"。

## 1. 目标

交付 v0.1 的核心价值闭环：**导入一次 → 规划 → 多目标分发 → 验证 → 卸载，全程可审计**。

完成时必须满足：

- 本地目录与 ZIP 都能导入为受管 Skill 版本（内容寻址、去重、Zip Slip 被拒）。
- 任意分发先生成只读 `DeploymentPlan`，8 种 `ConflictKind` 各有单测覆盖。
- Copy / Junction 两种 Driver 都能 安装 → 验证 → 卸载；故障注入不破坏原目标，不残留半成品。
- 多目标执行支持部分成功；每个写操作落 `operations` 表，每次安装落 `deployments` 表。
- 全部新增逻辑有单测；`cargo test --all-targets` 与 `clippy -D warnings` 全绿；前端 `npm run check` 全绿。

## 2. 范围与不做

- 做：Task 7（导入）、8（Plan + 冲突）、9（Copy Driver + 补偿事务）、10（Junction Driver + 验证 + 卸载）、11（多目标执行 + Operation 审计），以及把它们接通的 Tauri command + DB/AppState 接线。
- 做（Task 12 子集）：Library 列表 + 导入、分发向导、操作记录三个前端页面，使闭环可在桌面端走通。
